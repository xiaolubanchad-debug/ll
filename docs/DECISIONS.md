# 架构决策记录

基线版本 1.0.0，日期 2026 年 10 月 27 日。后续修改保留原决策记录，新增替代决策及原因。

P3 增量决策（1.4.0，2026 年 10 月 28 日）：采用固定的 Appium WebDriver HTTP 适配器替代 WebdriverIO，以明确保证变更命令单次传输；仅查找和核验有界轮询。HTTP 代理通过节点本机转发器注入认证，不将口令放入模拟器参数。截图使用受鉴权的有界 JSON/Base64 PNG，减少 multipart 接口与临时文件处理，原始 UI 树不上传。详见 [P3 契约](P3_CONTRACT.md)。

| 编号   | 决策                                          | 原因与代价                                                                 |
| ------ | --------------------------------------------- | -------------------------------------------------------------------------- |
| ADR001 | 自研业务采用 Node.js 24 与 TypeScript         | 前后端及节点共享类型和协议；仍需 Python 运行 Ansible、Java 运行安卓工具    |
| ADR002 | 中台与执行节点分离                            | 现有 Hostinger 可承载中台，EC2 承载安卓；需要节点通信和状态恢复            |
| ADR003 | SSH 首次安装，HTTPS 主动拉取任务              | 日常无需节点公开管理 API；需要注册、鉴权和心跳                             |
| ADR004 | 部署采用 Ansible Runner CLI                   | 保留可重复安装和结构化事件；部署 Worker 独立运行                           |
| ADR005 | PostgreSQL 保存队列与租约，第一版无 Redis     | 减少基础设施；仍需事务、唯一约束、超时及 fencing，不能只用内存锁           |
| ADR006 | 一批次一个节点，每节点一个执行槽              | 限制并发冲突和重复注册；多节点分片和复制不在 v1                            |
| ADR007 | 配置、凭据版本和发布版本在批次创建时固定      | 运行可追溯；编辑配置不会立即改变运行中的节点                               |
| ADR008 | 节点本地 SQLite 保存提交记录和结果待传队列    | 掉线后保留证据；不能保证产品端恰好一次注册                                 |
| ADR009 | 提交意图持久化后不自动重放注册                | 宁可保留 UNKNOWN 也避免创建重复账户；需要管理员核验                        |
| ADR010 | 合法测试环境隔离，不承诺真实手机指纹          | 可验证 Android 环境与应用行为；真实身份覆盖另需实体设备                    |
| ADR011 | 契约优先，Schema 与反例纳入检查               | 减少前后端约定漂移；协议变更需要同步更新文档、样例和检查                   |
| ADR012 | 管理界面只用中文业务术语                      | 对外不暴露不必要的实现细节；错误仍保留可查询的错误码                       |
| ADR013 | P0 保持 Prisma 6.19.3，并固定修补过的间接依赖 | 使用可验证的迁移流程；deepmerge-ts 与 multer override 必须随更新做兼容测试 |
| ADR014 | P0 生成静态校验器并在浏览器与 API 共用        | 不要求浏览器开启运行时 eval；共享类型只表达结构，条件约束由运行时校验负责  |

用户已明确的约束：URL 与 XPath 在中台填写；网页不使用代理；安卓使用 HTTP 住宅代理；账号为 6–10 位英文、密码为 8–12 位英文与数字；手动开始和停止；不开发 APK 产品后台。

第一版工程默认：一批次一个节点、每个入口一次注册、同节点当天缓存下载、未适配流程跳过、断线后不自动迁移注册任务。可在后续需求中调整，但必须先更新开发契约和验收场景。
