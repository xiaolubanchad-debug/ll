## P0 工程基础

交付 npm 工作区、TypeScript strict、NestJS 与 Vue 骨架、PostgreSQL/Prisma 迁移、配置环境样例、管理员初始化与会话、统一错误响应、Schema 生成类型和 OpenAPI。根 npm 命令统一为 lint、typecheck、test、check:contracts、build。

验收：空数据库一条迁移命令建立结构；无默认密码；未登录不能读服务器或任务；前后端均能拒绝非法配置；Schema 与接口差异检查在 CI 运行。开发用例不需要 EC2 或实际凭据。

## P1 服务器管理和部署

交付服务器录入、密钥或密码连接、主机指纹确认、环境检查、发布管理、部署 Worker、Ansible Playbook、Agent 注册、心跳、版本和能力展示。

验收：中台添加一台测试 EC2，测试连接，点击部署，看到步骤进度，节点上线，通过安卓能力检查。错误密码、指纹不符、无 KVM、磁盘不足各自有明确失败原因。重复部署不丢失数据；忙节点拒绝升级；两个部署进程不能同时占用同一节点。

证据：一次完整部署事件、节点就绪报告、重复部署结果、故障用例结果。生产条件未准备时只标记模拟验收通过，不标记真实 EC2 通过。

## P2 配置下发和 APK 下载

交付不可变配置版本、秘密版本引用、任务创建与领取、租约、幂等、停止、Playwright 发现与下载、按日缓存、APK 校验和结果回传。

验收：自有测试站同时覆盖直接下载、新标签页落地页、同页跳转、轮播重复元素、失效链接和非 APK 响应。同一天命中缓存，跨日重下；篡改缓存文件后不能继续安装；超过目标上限明确失败。两台节点可执行不同批次，但同一节点不能双占用。

证据：浏览器测试页面、原始与重复点击请求、数据库占用结果、脱敏日志、停止回执、APK 元数据。

## P3 安卓与注册适配

交付独立模拟器、HTTP 代理接入、ADB 安装启动、Appium 流程配置、账户生成、唯一提交点、结果证据和清理。

验收：先用自有测试 APK 覆盖成功、明确拒绝、提交后超时和界面变化；再为用户提供的代表性 APK 配置流程。找不到流程必须 SKIPPED。代理口令不出现在进程参数、错误或截图索引中。真实出口与设备标识按证据记录，不推断为真实手机。

证据：至少两个不同注册流程、APP_UI 成功截图、UNKNOWN 用例、进程及目录清理结果。没有 APK 样本时，模块可完成模拟验证，但不能声称业务注册已经跑通。

## P4 故障恢复与交付

交付结果补传、重启协调、旧 fence 隔离、凭据吊销、受控升级与回退、备份恢复、审计、操作手册和发布包。

验收：Agent 或中台在提交前后分别重启；提交过的任务不重放；失联节点不可重新占用；停止指令保持到节点回执；迟到事件不覆盖新状态；从备份恢复后先隔离未完成任务。校验发布摘要失败必须停止部署。

## 强制场景矩阵

| 场景                       | 预期                       | 阶段   |
| -------------------------- | -------------------------- | ------ |
| 相同幂等键重复开始         | 同一 runId                 | P2     |
| 同键不同请求               | 409 IDEMPOTENCY_CONFLICT   | P2     |
| 两个请求竞争节点           | 一个成功，一个 NODE_BUSY   | P2     |
| 下发成功、ACK 丢失         | 同 delivery，不执行两次    | P2     |
| 节点离线后停止             | STOP_REQUESTED，不伪造回执 | P2     |
| 租约过期且节点仍存活       | 停新动作、隔离、不迁移     | P4     |
| 注册提交后断网             | UNKNOWN，账户记录保留      | P3     |
| Appium 内部尝试重试 submit | 测试失败，禁止发布         | P3     |
| 旧 fence 回传              | 仅收为待核验证据           | P4     |
| 配置执行中编辑             | 原批次版本不变             | P2     |
| 凭据引用版本被吊销         | 拒绝新下发                 | P4     |
| 日志或异常包含秘密         | 检查失败，禁止发布         | 全阶段 |
| 缺失成功标识               | 不计注册成功               | P3     |
| 任务清理失败               | 节点隔离，不能继续下一批   | P3     |
