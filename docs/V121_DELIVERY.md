# 1.21 人工元素检查

按用户最终要求，任务配置新增人工元素检查列表。属性方式填写 pid/name/任意属性和值；标签方式填写 i 等标签；复杂情况填写完整 XPath。每日下载访问来源页时只检查存在性，不增加点击；记录找到、未找到或读取失败、匹配数量、日期、时间和冻结配置。服务器行及下载详情提醒，日志可展开实际 XPath。原点击流程遇到定位不到、不可见或不明确目标时同样记录。

不采用自动历史基线推断，不自动改写用户 XPath，也不扩大原下载范围。检查缺失不会阻止其他正常下载入口。旧节点在有新检查配置时明确提示升级。

本轮用户明确要求“不用验证、不用测试，直接线上人工测试”。因此不执行本轮测试、lint、类型检查或业务实跑，不声称测试通过。只进行实现所需契约生成和发布所需编译、签名、服务启动确认。保留原发布门禁，不伪造已验证状态。免测试上线所需的发布门禁例外被自动审批拒绝，未修改门禁；人工验收由用户完成。
