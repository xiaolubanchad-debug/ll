# 1.8.1 显式下载复跑

版本 1.8.1，2026-10-29。普通开始、续跑和每日调度仍复用当天下载。只有管理员明确执行 RETRY_DOWNLOAD 时，才允许对本节点、本配置、当天最新的 FAILED / CANCELLED / PARTIAL_FAILED 下载建立一次关联复跑；SUCCEEDED 或正在执行、清理未知的下载不能被自动重跑。旧批次和失败记录保持原样。

新轮次持久保存 downloadRetryOf，正常串联代理检查、下载和有限 N/M 注册，停止仍立即阻止新阶段。复跑下载的幂等键包含旧批次 ID，相同关联请求不重复访问；后续普通开始复用当天最新批次，不能退回最早已取消批次。只有人工操作可以建立下一次复跑，没有自动循环重下。

已停止的下载在任务中心显示“下载已停止”，不笼统归类为下载失败。未提交的下载错误仍为失败，部分成功仍单独统计。程序不得为推进流程改写原状态、伪造文件校验、重复已提交注册或放宽未知结果规则。现有 Agent 0.6.0 的缓存继续逐文件校验，已成功文件可命中，不必再次下载。

验收覆盖重试幂等、旧状态保留、成功下载禁止复跑、跨节点/配置/日期/活动批次拒绝，以及停止竞态。真实网站与产品注册另记实测证据。

Agent 0.6.1 修复下载页面范围：图标点击前记录来源页的实际地址（包括网站重定向后的地址），新窗口打开后不在未导航的来源页执行通用落地页规则；同页导航仍处理，直接下载及自动下载监听保持。每个页面中同地址、同规则、同候选只点击一次，防止同一个按钮消耗全部落地页次数。点击次数和超时上限不增加。测试覆盖首页重定向、无关下载按钮、延迟新窗口下载及同页落地页。0.6.0 仍兼容中台，真实复跑需先部署签名 0.6.1。
