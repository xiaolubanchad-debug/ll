# 1.17.1 下载修复与验证范围

本版为中台 1.17.1 / Agent 0.14.1。日常操作、单模拟器、10 秒停留、每日缓存及服务器额度沿用 1.17，不自动开始已有任务。

修复内容：

- 二进制清单同时存在整数 typedValue 与原始文本 rawValue 时，正确读取系统要求和版本号。自有合成结构样本在旧版本报 APK_INVALID，修复后读出 minSdkVersion=29、versionCode=12。此结果不代表历史第三方包已被重新检查。
- 触屏操作异常不再被吞掉，命令未确认时不会记录“已操作”或补点。准备、成功返回、收到下载事件与文件保存完成分别记录。
- 新记录区分未收到下载文件、图标/下载控件操作未确认、传输超时/中断，以及 ZIP、CRC、清单格式或元数据校验问题。旧记录继续显示原因未细分，不回填推测原因。
- 下载目标页使用“下载阶段”，不再显示尚未进入注册。错误码对应中文说明。

不会放宽 APK 完整性和安全限制。有效包仍需要通过大小、ZIP 条目、CRC、清单、包名及 SHA-256 检查；无效文件不进入有效缓存。没有增加入口搜索、请求回退、页面抓取或重试范围。

验证覆盖自有二进制结构正反例、本机 Chromium 的遮挡控件、无下载事件、挂起传输、HTML 假包、正常包、停止和工作目录清理，以及 PostgreSQL 的事件和缓存联测、浏览器中文结果显示。原生 Java 客户端没有改动；本机无 JDK 的该项测试仍标记跳过，不能算作通过。

部署及自有验证另行记录。不访问、下载或适配成人内容入口，不重新开始既有业务任务；现有目标失败不因平台升级改为成功。自有页面与测试包通过不代表所有外部站点均已兼容。
