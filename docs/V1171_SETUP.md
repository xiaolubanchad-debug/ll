# 1.17.1 下载修复与验证范围

本版为中台 1.17.1 / Agent 0.14.1。日常操作、单模拟器、10 秒停留、每日缓存及服务器额度沿用 1.17，不自动开始已有任务。

修复内容：

- 二进制清单同时存在整数 typedValue 与原始文本 rawValue 时，正确读取系统要求和版本号。自有合成结构样本在旧版本报 APK_INVALID，修复后读出 minSdkVersion=29、versionCode=12。此结果不代表历史第三方包已被重新检查。
- 触屏操作异常不再被吞掉，命令未确认时不会记录“已操作”或补点。准备、成功返回、收到下载事件与文件保存完成分别记录。
- 新记录区分未收到下载文件、图标/下载控件操作未确认、传输超时/中断，以及 ZIP、CRC、清单格式或元数据校验问题。旧记录继续显示原因未细分，不回填推测原因。
- 下载目标页使用“下载阶段”，不再显示尚未进入注册。错误码对应中文说明。

不会放宽 APK 完整性和安全限制。有效包仍需要通过大小、ZIP 条目、CRC、清单、包名及 SHA-256 检查；无效文件不进入有效缓存。没有增加入口搜索、请求回退、页面抓取或重试范围。

验证覆盖自有二进制结构正反例、本机 Chromium 的遮挡控件、无下载事件、挂起传输、HTML 假包、正常包、停止和工作目录清理，以及 PostgreSQL 的事件和缓存联测、浏览器中文结果显示。原生 Java 客户端没有改动；本机无 JDK 的该项测试仍标记跳过，不能算作通过。

部署及自有验证另行记录。不访问、下载或适配成人内容入口，不重新开始既有业务任务；现有目标失败不因平台升级改为成功。自有页面与测试包通过不代表所有外部站点均已兼容。

## 2026-11-02 上线核验

252 项契约检查、lint、类型检查、正式构建和完整 P0–P3/浏览器回归通过。补充的旧配置重试测试也通过：即使 retries=2，结果未确认的触屏也不会再发起。原生 Java 客户端未改动，本机缺少 JDK 的测试仍保留跳过标记。

中台 1.17.1 与签名 Agent 0.14.1 已上线。工具链与前一已验证版本一致，Android 镜像完整性、启动与新心跳检查通过。仅使用独立自有下载任务，十个客户端 APK 全部下载校验成功，总耗时 22.514 秒；十条触屏准备日志与十条文件保存后校验日志均正常入库。任务停止并归档，历史日志保留。

执行端实查十个自有缓存文件的大小和 SHA-256 均匹配，缓存占用已释放；模拟器、Appium、执行目录与占用槽均为零。该验证只下载，不安装或打开 APP，不增加 APP 尝试额度。已有业务配置版本、配置指纹、执行目标及停止状态均保留。

线上只读 UI 验证通过：旧失败记录显示未细分原因，没有推测回填；新阶段日志正常显示；下载目标使用“下载阶段”。未重跑原外部目标，不能据此承诺其全部下载成功。

## 发布耗时待改进

当前仍使用全量发布：完整回归约 7–10 分钟、中台构建约 3–5 分钟，EC2 安装还会复核固定依赖并逐个读取全部手机镜像计算校验值。本轮在补充旧重试保护后额外重建一次中台，进一步增加等待；自有十包下载本身仅约 22.5 秒。

后续应区分前端、业务程序和 Android 环境更新，保留签名与节点回执，为工具链不变的代码更新建立增量流程，SDK/镜像变化和定期维护仍执行完整校验。此优化尚未实现，本版没有跳过既有部署保护。
