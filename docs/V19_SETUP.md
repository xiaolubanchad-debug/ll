# 1.9 使用与验收

网页下载自动使用安卓手机模式，无需安装或控制管理员电脑上的 Chrome。来源和可读取的落地页会显示“安卓手机环境已确认”日志。网页 UA 留空即可；显式填写只接受 Android Mobile Chrome，旧的 iPhone 或桌面 UA 需要清空或更正。

开启自动寻找注册入口后，APP 启动、入口导航和填写前会处理明确的广告关闭/跳过控件及公告。等待倒计时、关闭广告和公告各有日志；不以点击广告内容代替关闭。关闭动作使用同一轮总预算，不反复消耗注册次数。手工模板同样先处理可识别遮挡；图片识别沿用配置中的截图识别选项。

安卓控件读取故障现在分别显示超时、连接、服务异常、会话丢失等原因。基础读取失败不再统称为注册流程需要适配。遇到未知页面、多个候选或无法证明成功时仍停止或暂停，不能由普通首页判断成功。

升级先关闭任务并等待节点清理确认，备份并更新中台，再发布和部署 Agent 0.7.1。无需数据库迁移；新事件需要更新中台后才能上报。旧 Agent 仍可运行原有能力，新功能以实际部署的 Agent 为准。

本地回归、Ubuntu 24.04 / 26.04、EC2 环境检查及实际产品联测分别记录。产品是否成功注册以本轮 APP 明确信号及有效证据为准。
