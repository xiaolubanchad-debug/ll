# 1.8 统一任务与历史管理契约

版本 1.8.0，2026-10-29。兼容 Agent 0.6.0，不改变节点协议、唯一注册提交或结果证明。主入口为任务中心，旧方案与执行记录继续可读，旧手工入口置于高级操作。

## 保存、执行与停止

ManagedTask 绑定一个稳定配置容器及执行节点；一次保存原子创建不可变配置版本并更新当前引用。默认不启动任务。旧方案须管理员显式接入，不自动启用现有计划或实际产品注册。注册配置必须具备代理及自动识别或有效手工规则。

开始操作立即创建或恢复北京时间当日轮次，并按 automatic 设置后续每日执行。调度在中台后台进行，重启可恢复，不依赖网页。每个轮次持久保存配置、目标、尝试上限、节点及发布快照，后台自动执行代理检查、每日下载、注册。代理检查失败不打开产品。任务、节点锁和持久幂等键阻止重复点击及多个调度器重复创建批次。

停止操作先持久关闭任务运行开关和后续每日自动执行，并标记轮次停止；后台向既有批次请求停止，等待原节点回执。失联或未知显示待确认/待核验，不伪装已停止，不释放隔离。停止与创建批次在同一节点锁下检查持久意图，不能在停止后偷偷建立下一阶段。

停止针对任务 ID 保存意图，不因界面版本稍旧而拒绝；其他编辑和控制操作仍需当前版本。已经达到目标的手动轮次再次开始不创建额外批次，也不留下虚假的运行开关。

停止事务立即取消所属未领取批次、向已下发批次设置停止标志；后台负责后续回执归并。任务开启期间节点归其管理，旧手工执行和部署入口必须先停止对应任务，不能在阶段间隙抢占节点。

停止后开始仅为未达到的目标及未使用的尝试额度建立后续批次；已提交轮次不回放，已开始的尝试永久计入上限。未知或清理不确定必须沿用现有人工核验和节点解除隔离流程，再显式开始。人工决议不覆盖自动成功计数。已达目标或尝试耗尽的轮次不自动追加；新增一轮是显式独立操作，有新的 N/M，并在界面说明会新增账户。

## 每日资产与编辑

每天的首次下载沿用稳定配置容器、节点和北京时间日期形成唯一键。保存注册规则、代理和配额不触发重新下载。当前日已有下载时使用该来源的 source/download 快照；若下载规则已修改，内部生成当天有效的注册配置并标记下载规则次日生效。不能把旧来源资产当作新来源下载。节点安装前仍校验本地缓存；文件丢失不能自动突破每日限制重新下载。新文件校验后清理昨日缓存仍由原执行端负责。

运行中编辑只更新未来轮次的配置。当前轮次包含固定目标与配置；停止后继续仍沿用原轮次额度；节点清理确认后，新的未提交尝试采用当前注册配置，已执行批次快照保持不变。更换节点要求无活动轮次；当日已有轮次需显式新增一轮使用新节点。时间默认 Asia/Shanghai 00:05。每天只建立一个自动轮次，手动新增轮次复用当天 APK。

## 生命周期与引用

配置容器、配置版本及发布增加 archivedAt/revision。默认列表隐藏归档项；历史详情保留。统一管理接口提供引用数、归档、恢复、删除和最多 100 项批量操作，整批原子校验，使用管理员会话、CSRF、幂等和 revision 防止陈旧删除。

未被引用的配置版本和空配置容器可永久删除登记；有历史引用的只能归档。正在运行、启用计划或任务当前引用的配置不能归档，错误说明引用位置。已被节点、节点凭据、部署、运行、计划、日记录或任务轮次引用的发布不能永久删除。归档发布不影响已安装 Agent 身份、心跳和既有任务，但不允许新部署。构件文件不在本次登记删除中物理清理；不删除节点文件、真实账户、证据或任务历史。

引用创建与生命周期变更共用数据库事务锁，不只依赖前端按钮。JSON 中旧计划及日快照的引用也计入删除限制。任务归档要求已停止且无待确认执行；恢复不会自动启动。旧入口不得绕过归档检查。版本恢复为草稿，另存新快照，不覆写历史。

## 验收

覆盖多次点击/多调度器、停止竞态、崩溃恢复、日界线、有限配额续行、未知不重试、代理失败、规则变更不重复下载、旧计划冲突、归档过滤、引用阻止删除、批量回滚、权限/秘密隔离，以及真实浏览器新建向导、主按钮和版本清理。生产发布只读验证，不自动启动产品注册。
