# P2 宿主机出口限制授权记录

下载器已实现本地强制 HTTP(S) 出口代理、逐连接 DNS 校验和地址固定、私网及 metadata 拦截、loopback 不绕过代理、禁用 QUIC 与非代理 WebRTC。本文件是额外宿主机限制的审阅范围，尚未安装或修改任何服务器防火墙。

开发契约的部署安全要求还包括宿主机出口规则。自动审批拒绝将此系统网络改动直接加入部署，理由是可能中断 Agent 网络、影响共享服务器，且缺少明确授权。

拟实施范围：仅目标 EC2 的专用 apk-runner 服务账号（部署时读取其数字 UID）；仅新增独立 nftables inet 表的 output 链，默认策略 accept。保留本机 loopback 通信，以及配置中台地址解析出的 IP 和 HTTPS 端口；拒绝该 UID 到私网、link-local、metadata、多播及保留网段。其他 UID、SSH 入站、已有表和系统默认策略均不调整。

启用前检查：目标是执行节点、apk-runner 没有承载其他服务、中台 HTTPS 可达、系统 DNS 使用本机解析服务。部署进度须记录规则安装失败，不能伪报成功。规则通过固定程序生成，校验数字 UID、IP 和端口，不拼接用户 Shell。

用户已明确确认“允许，仅限执行账户”。据此将规则安装器加入签名发布包及 Agent 服务启动前置步骤，并补充 Linux 语法测试。中台白名单来自 root 所有的 egress-policy.json，执行账户不能自行修改。撤销范围仅为本项目专用表；不清空服务器现有防火墙。真实 EC2 网络兼容性仍需实际部署验收。

本地开发和 CI 不代表已经修改真实 EC2；只有实际部署并核对规则后，才能声明该实例的宿主机限制已生效。
