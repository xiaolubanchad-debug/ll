# 1.10.1 APK 下载入口补充

2026-10-29，Agent 0.8.1。HTTP 文档版本 1.10.1；配置和节点协议仍为 1.0，无数据库迁移。中台先升级兼容列表，再发布和部署新 Agent。内容隔离、每日缓存、节点互斥、唯一注册提交和未知结果规则保持生效。

## 有界下载发现

网站及落地页保持 Android 手机屏幕和触屏。按以下顺序处理：监听直接/自动下载；匹配已配置的落地页控件（含 HTTP(S) 子框架）；匹配唯一、可见的明确下载文字控件；从当前落地页和子框架的链接属性、下载属性、onclick 字面量及内嵌脚本中静态提取唯一 APK 地址。源码只在节点内存中读取，不保存 HTML、脚本正文或图片。

补充发现仅在当前框架具有匹配的非 AUTO 落地页规则时开启。AUTO 仍只等待自动下载。补充发现至少等待 1.5 秒；已操作控件的同页不再通过补充文字或源码地址补发请求，避免延迟下载时抢先选择备用文件。明确下载文字包括“高速下载、立即下载、安卓下载、下载 APP、普通下载”；多个独立候选不能猜测。自定义选择器保持优先，不递归点击其他 APP 图标。

静态提取只处理完整、带引号的 HTTP(S)、协议相对、根相对或路径相对 URL，pathname 必须以 .apk 结尾（大小写不敏感），保留查询参数；可解码常见 HTML 实体和 JS 字符串转义。不 eval，不执行源码提取到的表达式，不拼接变量或解密脚本，不扫描任意外部脚本。候选有多个不同 URL 时不猜测，也不把正文提到的 .apk 文件名或包含 .apk 的查询参数当成安装包。

每个页面最多检查 16 个框架；每框架每秒最多静态扫描一次、最多检查 1,048,576 个字符，单值上限 4096 字符、最多 32 个不同地址；动作仍受现有 timeoutMs、maxLandingClicks、停止和租约共同限制。所有提取链接通过同一受限浏览器出口访问，保留手机 UA、Cookie 和来源，不使用无保护的 Node fetch 下载，不放行私网、凭据 URL 或非 HTTP(S) 协议。相同地址不重复请求；一次浏览器已产生下载事件后不再触发其他下载。

## 文件与日志

Agent 的持久执行根目录默认 /var/lib/apk-platform/execution；下载工作目录为 downloads/jobs，缓存为 downloads/cache/files/<cacheKey>.apk。注册从同一缓存键读取、重新校验后通过 ADB 参数数组安装，不依赖浏览器默认“下载”目录或图形文件管理器。

只有 APK 结构、包名、大小和 SHA-256 校验通过才原子写入缓存。返回 HTML、空文件或损坏 ZIP 均不得变为下载成功。失败工作文件清理，不改变有效历史缓存。固定中文 LOG 说明采用了配置控件、下载文字、源码 APK 地址或收到文件；日志不记录候选 URL、查询、HTML、页面正文或秘密。获取文件失败与 APK 校验失败仍使用既有错误码，不冒充安装或注册结果。

原实现拒绝 LOG 执行事件，本版只接收绑定当前 DOWNLOADING 任务、level=INFO 且 message 为上述四种固定消息或“下载等待结束：未收到浏览器下载文件”的事件；Schema 拒绝任意文本和未知字段，其他阶段拒绝。旧节点不发送该事件，继续兼容；这不是开放式日志或源码上传通道。

## 正反例与验收

正例：div/span“高速下载”触屏触发 APK；iframe 内唯一下载按钮；onclick 或内嵌 JSON 含唯一 https://downloads.example/app.apk?token=a%2Bb&channel=test；相对 /files/app.APK 地址；下载后缓存文件存在、指纹一致，注册接收同一绝对路径。

反例：两个不同 APK 字面量而没有唯一控件；文章正文出现“app.apk”；https://example.test/?next=app.apk；javascript:/data:/file:、带用户名密码或私网地址；动态表达式拼接、脚本代码执行；AUTO 模式提前点击备用按钮；提交注册超时后自动重发。以上不得作为可靠下载或注册成功。

使用自有页面和 APK 验证下载事件、源码发现、控件及框架、无效包、私网保护、重复请求、缓存路径及停止清理。真实产品与 EC2 部署另外记录，不能用自有测试替代。
