# 1.7 结果与日志中台

中台 1.7.0，2026-10-29。执行端继续使用已部署的 Agent 0.6.0，本次无需重新安装 EC2 的 Android 环境。规则见 [1.7 契约](V17_CONTRACT.md)。

## 日常操作

1. 工作台查看按北京时间日期汇总的成功、APP 明确拒绝、执行异常、待适配和未完成核验数量。人工决议另列，系统自有验收不计为产品注册成功。
2. 任务方案填写 URL、XPath，选择执行模式和已保存代理，可直接勾选自动寻找各 APP 注册入口；复杂落地页、设备参数及多步骤规则保留在高级设置。保存会建立不可变新版本，运行中的任务继续使用原快照。
3. 执行任务的“新建执行”选择服务器、方案和版本，先下载当天 APK，再选择循环注册及所有 APK 合计成功目标、尝试上限。不可开始时会说明未就绪条件。
4. 每日计划在独立分区管理，绑定服务器和配置版本明确显示。关闭计划与停止本批执行使用不同入口，停止后仍等待节点回执。
5. 注册记录按日期、服务器、结果、APP 或入口查询。每轮可查看最后阶段、原因、耗时、脱敏截图和经过审计的账户信息。未知结果保留原判定，人工决议不触发再次提交。
6. 执行详情默认打开中文日志，另有轮次与目标、证据与账户分区；地址可复制并支持刷新、前进后退和目标分页恢复。日志默认最新 100 条，持续增量读取，也可关闭跟随并向前翻阅；浏览器窗口最多保留 1000 条，历史仍保留在服务端分页查询。
7. APK 资源显示当天下载校验记录和声明的 ABI，不承诺文件仍在节点或一定可安装；安装前由执行端重新校验。代理管理可具名保存代理及独立发起连通检查，检查不打开产品 APP。
8. 系统设置中查看独立的系统验收结果，以及管理员密码和操作审计。先前自有 APK 验收属于此类记录，不会伪装为产品注册结果。

## 升级与数据

升级前备份数据库和部署配置，确认无活动部署或执行批次。应用 202610290001_v17 迁移，增加可空时间投影、最后阶段及代理名称；历史投影只从已应用且非迟到的事件回填。新增只读接口受管理员会话保护，不增加 Worker 或 Agent 的数据权限，也不改变注册、配额和代理执行协议。

中台后台每 15 秒检查既有租约到期规则，不依赖打开旧任务列表。到期或未知仍隔离，不释放为可执行任务，不自动重新注册。

本次验收使用隔离 PostgreSQL、真实 SQLite/Chromium、141 条合成注册记录及超过 200 条事件，覆盖首页完整统计、日期边界、错误分类、人工决议、日志翻页及续读、历史回填、后台租约检查、未授权查询和秘密隔离；浏览器覆盖任务地址与分页恢复、中文日志、筛选、方案、代理和每日计划复选框。正式发布以对应提交的检查、CI 和部署回执为准。生产验证只读取现有数据，不生成虚构产品记录或自动启动注册。

仍可后续扩展可配置的数据保留与清理作业、批量脱敏导出及更完整的适配管理。本次不宣称实际产品 APP 已完成注册联测。
