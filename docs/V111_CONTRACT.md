# 1.11 APP 启动准备与关闭确认

2026-10-29，Agent 0.9.0，HTTP 契约 1.11.0。节点和配置协议仍为 1.0，无数据库迁移。中台先升级，再部署签名 Agent。原始画面只在 EC2 内存中用于识别；不保存或上传图片、UI 树、OCR 正文、控件文字或定位器。唯一提交、提交未知不重发、节点互斥和清理回执保持生效。

## 启动准备

APP 启动后、寻找入口及填写前，依次识别明确的关闭/跳过控件、等待有效倒计时、执行单次关闭，并核对原遮挡是否消失。识别和确认均读取新快照，不以整页哈希变化代表关闭成功，也不因视频/背景动画变化重新点击相同按钮。关闭后的观察默认 3 秒、允许 1–5 秒，至少连续两次且相隔 300 毫秒确认候选消失；新的不同遮挡可继续处理。同一关闭候选未确认消失时不得自动重发点击。

文字子节点使用可核对的最近可点击父控件；禁止提升到全屏 WebView、滚动容器或包含输入框的整块表单。父子同目标合并，多个独立关闭候选停止待适配。公告确认须有公告语义；隐私同意沿用注册入口的独立规则。验证码、付费、外部包和系统权限页面不得混作广告关闭。

若原生“关闭”语义节点覆盖大部分屏幕，不得点击其中心。该语义只能作为存在模态遮罩的证据：同时找到中等尺寸、独立的前景容器后，可将其用于图形 × 的限定识别区域；只有实际识别出小型关闭控件并两次核对稳定像素才触控。支持容器上沿关闭图标及底部居中图标；没有可靠面板或图形证据时停止，不猜角落或遮罩外侧坐标。

原生控件优先，其次本地文字 OCR。纯图形 × 可在明确广告/公告/弹窗容器内、具有触控归属的小型 ImageButton/ImageView/View 控件区域中进行本地图标验证；须满足双对角、高对比和形状约束，并用两次快照核对相同目标和图形核心二值像素特征，允许最多 6/81 个采样点变化，不比较透明边缘的背景动画。两次形状检测都必须通过；没有可靠容器或控件归属、图形移动、图案不符、候选不唯一时不触控，不猜屏幕角落。识别不到图标不声称已关闭。

## 有界配置与兼容

可选 execution.autoRegistration.startup：confirmationTimeoutMs=3000（1000–5000）、splashTimeoutMs=15000（1000–45000）、totalTimeoutMs=60000（10000–90000）、maxActions=12（1–12）、iconRecognition=true。省略则新 Agent 使用默认值；图片图标识别同时要求既有 screenshotFallback=true。所有等待、读取及 OCR 都受剩余总预算、当前阶段期限、停止和租约约束；不延长注册提交核验期限。每次注册共享动作和总预算。

签名发布新增 APP_READINESS_V1。显式 startup 配置要求 Agent 0.9.0 与该能力，在创建、领取/接收和配置读取处检查；旧配置与旧 Agent 继续使用其原有行为。升级不改变已经分配的快照。

## 阶段日志

APP_OBSTRUCTION 增加可选 phase=DETECTED/WAITING/ACTION_SENT/CLEARED/UNCHANGED/UNVERIFIED，以及 method=ICON。既有 action 与 index 保留。ICON 必须带 phase；WAIT_SPLASH 只可 DETECTED/WAITING；UNCHANGED/UNVERIFIED 不代表注册结果。旧事件无 phase 时显示“已执行处理，关闭结果未核对”，不得继续显示成已经成功关闭。新日志只保存固定枚举和序号；中台以中文显示发现遮挡、等待倒计时/关闭、已执行、已确认、未生效或无法核验。

只在当前 APP、提交前的 LAUNCHING/DISCOVERING/REGISTERING 阶段接收事件。提交后保持只读结果核验，禁止关闭弹窗或重新提交。关闭失败仍为提交前失败；不会误记 APP 明确拒绝注册。

## 正反例与验收

正例：关闭按钮被点击后 2 秒才退场，等待后确认且只点击一次；广告倒计时→跳过→公告→注册入口；文字子节点归属于唯一可点击按钮；带明确弹窗容器的 × 图标两次稳定核对后消失；后台动画持续变化而目标不变，仍只操作一次；原生元素在点击前发生几何变化，记录无法核验并读取新快照，稳定后才执行，持续变化则在总时限结束前停止。

反例：150 毫秒未改变即断言失败；视频画面变化被当作关闭成功；多个关闭目标选一个碰运气；正文/输入框中的 x 或加号图案；无弹窗归属的图片、整屏可点击 WebView、移动图标、只点击未确认就记已关闭；停止或租约失效后继续动作；注册提交后处理弹窗再提交。以上均不得通过。

运行契约正反例、原生与 OCR/ICON 边界、延迟退场、候选合并、静止与动画停滞、预算和停止、日志接收与中文展示、既有唯一提交与 UNKNOWN 回归。自有 Android APK、真实部署、七猫缓存 APK 的有限复测分别记录；未执行或未提交不算注册成功。

本地完整集成及浏览器回归通过，契约正反例 179 项通过；原生几何变化增量修复的启动准备专项 12 项通过。EC2 自有 theta APK 在 5 秒确认配置下实际完成三类遮挡处理（SKIP_AD、ACK_NOTICE、ICON CLOSE_POPUP），均有 CLEARED；随后识别注册入口、仅向自有测试后台提交 1 次，并由 APP_UI 确认成功，清理完成。该结果仅证明自有样例，不代表第三方 APP 注册成功。真实凭据、APK 和执行证据不入仓库。
