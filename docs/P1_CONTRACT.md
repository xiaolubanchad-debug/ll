# P1 服务器与部署契约

版本 1.1.0。P1 提供服务器资产、加密凭据、主机身份核验、只读检查、固定版本部署、Agent 注册和心跳。无真实 EC2 时只标记本地 SSH 与模拟部署验收，不宣称安卓云端已通过。

服务器保存 SSH 用户、端口、不可变凭据版本引用及资产 version。修改和确认主机公钥使用 If-Match。主机或端口变化清除信任并撤销旧 Agent 身份；忙节点禁止编辑。指纹探测不发送登录凭据，管理员核对可信来源后填写 SHA256 指纹，不能将探测结果自动信任。

PROBE、CHECK、DEPLOY 共用部署作业表和节点槽。创建作业在事务内锁定节点，与运行任务互斥；创建和停止使用 Idempotency-Key。重复键返回原作业，正文变化返回冲突。Worker 从数据库领取，使用 workerId、租约和递增 fence 写入进度。过期作业进入 NEEDS_REVIEW，节点隔离，不自动重放远程安装。

执行节点接受 Ubuntu 24.04 / 26.04 LTS x86_64，具体正反例和验证边界见 [兼容契约 1.3.0](UBUNTU_COMPATIBILITY.md)。旧发布的 Playbook 摘要不变，新脚本需新签名发布。

只读检查返回 Ubuntu 版本、架构、内存、磁盘、KVM、sudo 和安装标记。完整部署在修改服务器前建立安装标记；异常无法证明结束时保持隔离。隔离节点可执行只读检查；只有管理员引用新的检查结果、确认无安装标记且无活动任务，才允许解除隔离。正在部署时的心跳不能释放占用。

SSH 使用固定检查脚本和严格主机公钥验证。Ansible Runner 使用结构化 inventory、独立 0700 工作目录、0600 密钥及密码文件；参数和事件中不含口令。日志只发布固定步骤名、状态和错误码，不直接转发远端输出。生产 Worker 只执行仓库内固定 Playbook，测试替身仅通过依赖注入提供。

私钥选择与 Runner 清理顺序遵循 [SSH 身份修复契约 1.3.1](SSH_RUNNER_FIX.md)；保留 IdentitiesOnly 与主机指纹检查，显式指定本次身份文件，并正确归类 OpenSSH 认证失败。

普通账户注册安卓驱动遵循 [驱动安装契约 1.3.2](APPIUM_INSTALL_FIX.md)，使用独立 npm 全局链接目录，保持 Node 运行时由 root 保护。Playbook 修复使用新的 Agent 0.3.2 签名发布。

SDK 规范目录和离线包元数据遵循 [SDK 安装契约 1.3.3](ANDROID_SDK_LAYOUT.md)，安装使用 Agent 0.3.3 的新签名发布；仅创建 AVD 不构成启动证明。

当前安装使用 Agent 0.3.4，服务启动步骤根据签名能力生成，见 [服务能力契约](AGENT_SERVICE_FEATURES.md)。

Inventory 中的字符串使用 Ansible 的 !unsafe 标记，确保特殊符号和模板片段作为原文传递；SSH 密码机制固定使用 sshpass。Linux CI 通过真实 Ansible 本地连接检查 SSH 与 sudo 密码的原文保持。

发布由本地命令打包 Agent 并签名，包含源提交、Agent SHA256、Playbook 摘要、协议版本和固定工具档案。管理员登记时验证签名和本地构件，不接受任意下载地址。依赖档案限定官方 Node 与 Android 主机、固定 URL 和校验值。Google 档案可使用其官方元数据中的 SHA1；Node 与 Agent 使用 SHA256。主版本、档案 revision 和 URL 固定到发布，不在部署时重新解析 latest。

注册令牌绑定部署及节点，有效期 10 分钟，只创建一次身份。完全相同的 bootId 注册请求可在有效期内重取同一派生凭据，以解决响应丢失；不同 bootId 或已撤销部署拒绝重用。凭据由主密钥与注册令牌派生，数据库仅保存摘要，Agent 本地加密保存。安装服务停止旧进程后才能创建新注册令牌。

Agent 接口仅接受 Bearer，不接受管理员 Cookie，也不要求浏览器 Origin/CSRF。它仍校验正文、节点绑定、协议和发布。心跳间隔 15 秒，45 秒未见即显示离线；P1 没有执行租约，非空 currentDelivery 被拒绝。Agent 不领取或运行测试任务。

部署成功需同时满足：固定 Playbook 成功、工具及空模拟器启动检查通过、Agent 在本次注册后回传心跳且版本正确。重复部署不覆盖已登记的健康 Agent 凭据，只有升级或重装才在停止旧服务后重新注册。取消是请求，停止控制进程后仍需确认远端安装标记；不能保证已安装的软件全部回滚。

Secrets、Releases、NodeOperations 的输入进入共享 JSON Schema；已实现接口清单由 P0 与 P1 清单合并生成 OpenAPI。私钥、sudo、代理口令及节点令牌不出现在普通资源响应、审计和页面日志。
