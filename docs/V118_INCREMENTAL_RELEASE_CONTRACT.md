# 1.18 增量发布契约

版本 1.18.0，Agent 0.15.0。用户要求普通代码更新仅发布相关模块；SDK、镜像、型号池或环境配方变化走完整环境校验。必要测试、签名、占用锁、幂等、停止及新心跳确认保留。

## 执行节点

DeploymentInput 新增可选 mode=AUTO|FULL，默认 AUTO；部署记录持久保存请求方式。AUTO 在签名发布声明 INCREMENTAL_DEPLOY_V1 且具有 environment 时检查环境基线。旧发布保持原全量流程。FULL 明确强制完整检查，不能被同版本复用快捷分支跳过。

签名 environment={version:1,recipeSha256,fingerprint}；fingerprint 由版本、完整固定工具链与固定环境源文件配方摘要计算。配方涵盖系统安装、镜像构建、型号目录、启动核验及基线算法，普通网页/APP 自动化代码不混入环境配方。基于已验证签名发布复用 npm 锁和工具链；依赖变化必须显式刷新环境，不能因抓取最新元数据暗中改变普通代码更新的环境。

首次没有可信基线时必须全量校验一次。全量安装成功后生成 root 持有的 environment-receipt.json：绑定节点、主机、环境指纹、实际全量验证发布与时间，保存不可变运行时、SDK、镜像、工具库及浏览器文件的元数据快照，并摘要核对控制清单。快照只记录路径和属性，不保存文件正文。明确排除运行目录、浏览器链接缓存与 Appium 的可变会话目录；驱动注册清单单独核对摘要。

代码更新逐项轻量检查基线和文件元数据，保留小控制文件摘要校验。基线缺失、格式/归属错误、路径/指纹不一致、文件增删或元数据变化时自动选择 FULL。此检查表达“复用此前完整校验且未发现元数据变化”，不冒充本次重新计算所有镜像 SHA，也不代替定期完整审计。

CODE 路径只安装已验签 Agent 程序及必要配置，复用 Node/SDK/浏览器/驱动，不运行 apt、sdkmanager、npm ci、镜像构建、全镜像哈希或全型号启动。准备和激活仍由固定 Playbook 完成；节点锁、远程安装锁、构件 SHA、配置保护、Agent 身份和全新心跳确认均保留。环境快速检查在持有安装锁且停止旧 Agent 后再次核对，变化时结束而不继续激活。失败/停止且远程安装标记未清理时保持隔离。

健康回执区分本次 FULL 与 CODE。CODE 保留实际全量核验的发布和时间，不把旧启动证据改成新启动成功。中台比对目标环境指纹、签名构建提交、协议和本次发布 ID，并等待新心跳。部署结果和界面显示采用的方式及原因。同一个现代发布也会走轻量一致性检查，不能仅靠旧心跳绕过漂移检测。

## 中台模块发布

建立受版本控制的发布规划、构建目标和宿主机发布入口。根据两个确定提交的差异，计算 web、api、worker、tools、agent 及数据库变更；共享依赖按实际依赖关系扩散，未知代码变更保守扩大检查。文档变更不重启服务。构建按模块进行，依赖安装层在业务源文件之前，普通源码变更复用依赖缓存。

宿主机发布只使用固定命令与参数数组，不向业务容器挂载 Docker socket。发布前后保存模块镜像与提交记录，验证已安装基础镜像固定摘要，持有数据库发布锁和宿主机锁；先确认没有活动任务、启用计划或部署。新 API 的启动/部署事务在发布期间给出维护提示；旧版本通过已有 library 锁阻止并发新增任务。只启动实际变化的服务，不重建或重启 PostgreSQL、不变模块和 EC2。中途结果不明时记录 NEEDS_REVIEW，不自动宣布成功；回滚只使用本次保存的既有模块镜像。

发布规划同时列出必要 lint、类型、契约、构建和相关测试。共享协议、数据库及发布机制的首次改造运行完整回归；之后支持相关测试选择，未知影响退回完整检查。测试选择不能代替实际运行结果；发布必须记录哪些检查真正执行。

## 正反例与验收

正例：只改 web 只发布 web；只改 automation/agent 只生成 Agent 签名程序及所需发布工具；环境指纹相同且基线有效时用 CODE；改 SDK、镜像或型号目录、基线文件漂移、显式 FULL 则完整校验。基线不存在时的一次全量建立与后续增量耗时分别记录。

反例：人工勾选跳过验签；仅比较版本名；没有基线就声称复用通过；在 CODE 中改 npm/SDK；伪造新的全量启动时间；跳过新心跳；发布中启动新任务；丢失错误却报告成功；把 APK、凭据和原始执行证据提交 Git，均拒绝。

验证包括规划依赖关系、签名/环境摘要、基线和元数据漂移、强制全量、部署锁与幂等、停止和未知结果、真实 PostgreSQL/Chromium 回归、宿主机构建缓存及模块重启范围。EC2 先建立全量基线，再实际执行一次签名代码增量更新，核对方式、耗时、构建提交、新心跳和资源清理。已有任务及配置保持停止和原样；不运行外部 APP 目标。
