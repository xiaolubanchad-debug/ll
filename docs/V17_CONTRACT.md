# 1.7 中台结果、日志与操作流程

版本 1.7.0，2026-10-29。本次仅扩展中台 API、数据投影和管理界面，兼容现有 Agent 0.6.0；不改变注册提交、节点锁、配额、未知结果、代理及每日下载规则。

## 结果和统计

增加受管理员会话保护的 GET /console/overview、/console/runs、/registrations、/registrations/:id、/runs/:id/summary、/runs/:id/timeline、/apk-assets、/console/validations。查询及响应在 v17.schema.json 声明，未知字段拒绝。日期按北京时间自然日，日期必须真实、起止有序且最多 31 天；列表最多 100 条，游标绑定筛选条件，采用时间和 ID 的稳定排序。首页统计由数据库汇总，不以当前页长度代替总量。

一条注册记录对应一个实际进入执行的轮次；REGISTER 中未执行的配额槽位不列入注册记录和尝试统计。旧 FULL 流程的注册阶段及跳过项可追溯。类别为 SUCCESS、REJECTED、ERROR、ADAPTATION、UNKNOWN、SKIPPED、STOPPED、PENDING。明确拒绝需要 APP_UI 及提交引用；提交前的代理、安装等错误归 ERROR。UNKNOWN 的人工决议另列，不覆盖原始自动结果、不冒充自动成功。截图、账户和核验沿用现有鉴权、脱敏和查看审计。

结果列表只含允许的名称、包信息、配置及服务器摘要、轮次、时间、结果、阶段和账户是否存在；不解密账户或代理、不含 URL 查询串、存储路径和秘密。仅账户专用接口可显式查看密码。APK 资源页展示文件校验记录，不能把历史元数据当作节点文件仍存在的证明。

## 时间和历史

Task 增加 startedAt、registrationStartedAt、finishedAt、lastStage 投影。有效事件在原事务内按序更新；只读查询不推进业务状态。历史回填仅使用已应用、非迟到且属于同一批次的事件，时间采用中台接收时间；缺少可靠数据时保持未知，不编造耗时或阶段。UNKNOWN、过期租约和清理失败不会因 UI 升级而释放节点或自动重跑。

既有租约过期检查由中台后台每 15 秒执行，不依赖管理员打开某个旧列表页面；仍使用原有 expireRuns、数据库锁及隔离规则，不增加自动重试。

## 执行时间线

使用已持久化事件生成中文记录，不开放任意 LOG 文本或 Appium/ADB 转发。响应只选取白名单字段，包含序号、事件时间、接收时间、任务引用、阶段、结果和错误码对应中文说明；迟到及未应用事件明确标记，不能冒充已生效结果。

时间线默认读取最新一页；afterSequence 增量向后读取、beforeSequence 向前读取，二者不能同时传入。每页最多 100 条，返回 hasEarlier/hasLater 和范围。界面去重追加、断线续读、支持查看更早记录和暂停跟随；不会每次刷新都停留在最早 100 条。没有独立清理证据时不生成“该轮已清理”事件，清理状态以批次确认回执为准。

## 页面和操作

菜单包含工作台、任务方案、执行任务、注册记录、APK 资源、服务器、代理管理、系统设置。任务详情有独立可复制地址，支持刷新及前进后退；筛选条件写入地址，不在浏览器存储秘密。创建执行、每日计划、历史记录分区展示；所选服务器和配置版本始终可见，停止本次与关闭计划分开表达。

任务方案以 URL、XPath、模式、已保存代理及自动识别表单为主，JSON 放入高级设置。保存仍产生不可变配置版本，不改变运行中的快照。代理管理独立保存凭据和显示检查结果；新凭据可有非敏感名称，旧凭据继续兼容，列表不得返回认证用户名和口令。

系统验收单独展示 Deployment 中已标记 ownedFixtureValidation 的记录；不导入或伪装为产品注册记录。无产品注册记录时说明如何下载并建立注册批次，不展示虚构成功数据。

## 验收

覆盖超过 100 条事件、分页追读及断线、超过一页的数据库统计、北京时间日期边界、错误和未知分类、人工核验不改原结果、迟到事件隔离、非法及跨筛选游标、未授权查询、秘密不出现在普通响应，以及浏览器刷新/返回恢复任务、筛选和中文日志。发布、生产部署、自有测试与实际产品注册分别报告。
