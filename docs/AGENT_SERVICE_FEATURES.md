# Agent 服务能力开关契约

版本 1.3.4，日期 2026 年 10 月 28 日。补充 P1/P2 服务部署，不改变 HTTP 结构、节点协议或节点占用恢复规则。

部署 Worker 从已验证签名清单的 DOWNLOAD_V1 能力生成布尔 download_enabled，传给固定 Playbook。systemd 模板根据该能力加入 root 身份的固定 egress.js 启动准备命令，不再维护另一份 Agent 版本白名单。未传能力变量必须拒绝渲染，不能静默省略网络准备步骤；旧 P1 无下载能力时仍不运行该命令。

规则继续仅约束 apk-runner 的出站，不改变其他账户或 SSH 入站。主机规则生成逻辑和先前授权范围不变；不接受用户配置任意命令或防火墙文本。新签名发布使用 Agent 0.3.4，旧发布保持不变。

正例：DOWNLOAD_V1 发布通过真实 Runner 传递开关，当前或未来版本服务均包含固定启动准备命令；无此能力的旧 P1 不包含该命令。反例：模板变量缺失时失败，不能把未配置准备步骤的服务视为完成安装验证。

测试包括真实 Ansible 模板正反例、真实 OpenSSH/Runner 参数传递和执行账户规则语法；实际 EC2 部署另核对启动准备命令成功、仅执行账户的规则已加载、Agent 注册心跳及安卓启动证明。
