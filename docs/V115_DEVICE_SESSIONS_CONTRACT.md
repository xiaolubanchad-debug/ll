# 1.15 多 APP 设备会话

版本 1.15.0，Agent 0.13.0，自有测试 APK 1.1.0。用户授权：型号池扩充 30 款、十个独立测试 APP、每台新模拟器随机执行多个不同 APK、两路真实验收。

## 配置与兼容

新增可选 execution.appOpen.appsPerDevice={min,max}，整数 1<=min<=max<=10；缺省保留旧单 APP 行为。需要明确 concurrency、contentIsolation=true、签名能力 DEVICE_SESSIONS_V1 和 Agent 0.13.0。注册表单模式不支持会话复用。配置先经 Schema 与跨字段校验。旧配置/批次/账户不迁移。

新的中台执行快照冻结 sessions（id、variantId、assetIndexes），按 APK 实际包名去重，并按兼容系统/ABI 过滤；同一会话无放回随机抽取 min..max 个 APP，末组可小于 min。失败也消耗尝试，不在同一会话重装同包。不同会话可以复用缓存 APK。选包数量超过可用兼容包数明确拒绝；不通过改文件名规避去重。型号以设备会话为单位轮换，池用完重新洗牌，相邻及并行会话不得使用同型号；不再要求整批所有 APP 型号不同。

N=APP 前台停留完成数，M=APP 已开始尝试上限，日额度继续按 APP 尝试累计（800），不是设备数或账户数。两路共享已完成及执行中名额，不能超开；设备会话内串行、设备之间并发 1/2。每个 APP 领取前在节点锁内校验 fence、停止、日截止、总预算和本会话顺序。来源及 APK 元数据必须与冻结资产一致。

## 生命周期与结果

每个会话仅启动一次新 AVD/独立数据分区，不使用旧运行快照。每个 APP 执行：校验缓存 -> 安装 -> 注入该 APP 专属短期凭据（自有客户端） -> 打开 -> 有界启动弹层处理 -> 确认前台停留 10000ms -> force-stop -> 卸载并确认 -> 关闭本 APP 的代理连接。随后执行本会话下一 APP；最后关闭 AVD、Appium、代理及目录并写会话清理回执。屏幕全程竖屏触控，内容隔离默认开启；不上传原始页面/截图。APP 开屏/公告使用既有受限处理器，不能自动执行注册/支付/未知按钮；无法处理明确失败，不把广告上的等待当作处理成功。

新 APP 结果明确 cleanupScope=APP_UNINSTALLED，含 deviceSessionId、appIndex；旧 cleanupComplete 的整机清理语义不改。会话 STARTED/CLOSED/FAILED 事件持久化并校验归属；RUN_FINISHED/STOP_ACK 必须等全部会话关闭，失败清理隔离节点。单 APP 安装/启动/广告失败可继续下一个不重复 APP；停止、失去租约、资源清理失败立即停止新增并清理。崩溃/重启只清理，不恢复任何已打开的 APP，不自动重复未知账户创建。

型号/系统/屏幕在同会话内不变；相同签名客户端可能共享 app-scoped Android ID，按实际观测记录，不能把十个 APP 当作十台设备。每个 APP 关闭前一连接并建立新代理请求，不额外探测/保证出口不同。自有客户端请求 UA 可配置，第三方 UA 未验证。每个 APP 有独立 token、installationId、requestKey；重试保持同键，不能跨包/任务复用。

## 型号与系统镜像

受版本控制的白名单包含 30 款真实机型参数（小米/Redmi 12、三星 12、华为 6），来源链接、实际 model/brand/manufacturer、屏幕参数和系统 API 映射。使用可校验的官方 SDK 基础镜像生成受控 QA 变体，保留模拟器、真实 ABI 和镜像来源，不冒充厂商 ROM/硬件认证。多版本按真实 SDK 镜像启动；仅已下载校验并实际启动核对的档案可发布为可用。不能把只修改版本字符串当作多系统支持。缺失镜像/不支持布局/启动不符必须失败，不静默回退 API35。旧 qa-model-01..03 为历史兼容档案，不算新增 30 款。

## 自有十包与界面

同一份客户端源码生成 1.apk..10.apk，独立包名 com.apkplatform.testclient.app1..app10、显示名测试 APP 1..10、独立 SHA、相同私有测试签名。现有单包发布与历史继续可用。公共来源页面为十个固定发布链接；下载和 token 发放核对已发布包名/SHA 配对，不允许任意文件/包名。仅中台任务启动；每包回执可归属设备会话和 APP 子任务。可控自有开屏/公告用于验证处理，不引入第三方广告 SDK。

任务向导提供每设备最少/最多 APP 数量，显示设备并发和 APP 完成目标。执行日志按设备会话/APP 展开，含抽取顺序、设备/APP 各步骤耗时、清理和上报状态；测试数据增加包名及设备会话关联。开始/停止保持统一入口。当天只下载一次、缓存 pin、跨日排空和 00:05 下载规则保持。

## 验证正反例

正例：10 个不同包，min=max=3，N=M=6，两会话并发，各三个互异 APP；实际仅两次设备启动，六次前台停留和卸载、两个整机清理；同会话型号一致，实际账户另计。尾组仅剩一个目标则只执行一个。单个 APP 失败不重复抽取该包；未开始不消耗额度。

反例：同 SHA 改十个文件名、相同包多个版本、min>max、max>10、兼容包不足、旧节点、新会话冒用旧 serial、同会话并行 APP、并行型号冲突、超过 N/M/日额度、APP 未卸载就下一包、会话未清理就成功/停止确认、token 跨包、未知回执换键新建、未验收档案宣称可用，全部拒绝或隔离。

契约/单元/数据库/浏览器/构建通过后提交并发布。另记录 30 款档案实际就绪范围、十个安装包校验、EC2 两设备并发的 APP 执行数量/随机无重复/广告关闭/前台停留/真实上报/停止与清理、总耗时与各步骤；未实际执行的范围不能宣称通过。

固定安装器对六个官方 SDK 镜像分别锁定地址/校验值；本版实际覆盖 API 29/31/33/34/35/36（Android 10/12/13/14/15/16）。机型名单见 [30 款档案](DEVICE_CATALOG.md)。构建只对私有变体回收零填充磁盘块，保持字节摘要一致；保留至少 20 GiB 可用空间，不清除旧版本来强行安装。首次安装的固定超时为 2 小时，仍保持节点锁和 Worker 租约。

逐款启动核对同时收集系统实际声明的 ABI 列表。只有与当前 SDK、型号、API 和镜像摘要匹配的启动回执才能封存为可用；节点心跳携带 ABI 摘要，计划冻结本会话 ABI 能力用于选包。不能把 x86_64 宿主机直接等同于所有镜像只支持 x86_64，也不能未经观测承诺 ARM 转译可用；实际安装/启动仍单独验收。步骤耗时新增镜像校验和 APP 控制服务准备，最多 12 个固定步骤。

网页下载仍是每天独立的一次安卓手机浏览器流程，使用下载配置的浏览器模板；APP 安装使用会话冻结的真实系统版本。网页 UA 不作为 APP 请求 UA 的证据。设备会话与 APP 统计分别展示；“会话开始”包含准备阶段，不能单独证明模拟器已成功启动。
