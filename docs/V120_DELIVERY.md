# 1.20 文件资产与停止收尾

当前 APP 测试按 APK 文件名选择和复用，下载、补包不再读取清单或包名。相同包名的两个不同文件允许串行安装、打开和卸载；安装后通过 Android 系统确认控制包名。旧无文件名缓存使用稳定历史名称兼容，不伪造原始文件名。

修复 NEEDS_REVIEW 被停止逻辑跳过的问题。普通 APP/下载测试收到停止要求后，仅在本批次清理回执和当前执行端的新空闲心跳齐全时自动回收占用。迟到回执、重复停止、错误 boot/fence、未知提交和未确认清理分别处理。原异常终态保留，新增 stopConfirmed 使已收尾执行显示已停止；同一 boot 的异常不再记为执行端重启。

本地验证通过 273 项契约检查、lint、类型检查、构建，以及文件接收/手机浏览器下载/缓存、APP 打开、设备会话、补包、任务中心停止和服务器界面的相关测试。停止专项 9 项使用真实 PostgreSQL 验证，浏览器/缓存使用真实 Chromium/SQLite；Android 安装与包名发现为模拟边界，不能称为真实设备安装验收。本次不运行第三方网站、APK 或注册流程。

线上原 55 停止批次已通过既有核验领域接口确认清理并解除占用，节点在线空闲、所有任务保持关闭，没有修改业务配置或开始新轮次。中台 1.20.0 / Agent 0.16.0 的增量发布结果另行追加；SDK、系统镜像、型号池不变。
