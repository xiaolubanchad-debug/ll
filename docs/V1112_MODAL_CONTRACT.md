# 1.11.2 原生弹层返回关闭

Agent 0.9.2，HTTP 1.11.2，2026-10-30。沿用 1.11.1 的读取、分阶段期限、独占执行、内容隔离和唯一提交规则。

在账户生成前的启动/入口发现阶段，明确原生关闭控件与图形关闭识别均未得到可操作候选时，可使用一次 Android 返回关闭有原生关闭语义的弹层。必须同时满足：当前 APP、唯一的整屏关闭遮罩、其内可唯一定位的非整屏原生面板/正文区域、没有输入或勾选控件、没有注册/登录/同意入口、没有隐私协议或身份/年龄/验证码挑战。不能用返回绕过验证或同意，也不能根据固定坐标关闭。

优先使用既有明确关闭按钮与可靠图形关闭；通用返回只作为有原生证据的后备。整屏关闭遮罩不能在中心点击。候选使用遮罩与前景区域两个当前对象引用，点击前核对两次新快照、唯一定位和边界；返回后两者均被同一会话明确判定失效，连续两次且至少相隔 300 毫秒才计为 CLEARED。只重建其中一个控件、背景动画、disabled、读失败或新画面均不足以确认。未确认不重复返回，不重建模拟器来重试该动作。

多个不相包含的前景区域、缺少前景对象、失去租约、停止、账户已生成、已提交或未知结果，均不获得通用返回权限。沿用同一个 readiness 的累计时限与动作上限，不重置预算。事件仍为 APP_OBSTRUCTION / CLOSE_POPUP / BACK，带既有 phase；不新增接口或配置字段。旧签名发布不改变，后台先更新版本兼容再部署新 Agent。

正例：广告缺少可验证的关闭图形，但有明确原生关闭遮罩和唯一前景对象；返回后两个旧引用均失效，继续发现新入口。账号保存说明只有保存功能和关闭遮罩时可返回，不能点击保存来获得权限。反例：普通内容页按返回、只有整屏遮罩而无前景对象时猜测返回、两个候选面板时选择最大的、注册/验证码页按返回绕过流程、用返回消失认定注册成功。

只复用已下载 APK。前轮未提交的失败留存不变；修复后可以由本次人工开发实测建立新轮次，每轮最多一次尝试；绝不复活或重发已提交或未知任务。自有 Android 验证与真实产品注册分别记录。

入口定位是只读操作。若定位失败且下一份新快照已证明页面或遮挡改变，可在同一发现期限和观察次数内重新识别新页面；不发送旧入口点击，不消耗导航步数或生成账户。若页面未改变则保留原定位错误，不无限重试；点击失败不能使用这一规则重发。

启动加载整句识别兼容受限等待修饰语“稍等一下/一会儿/片刻”和功能提示中的标点、符号及格式字符；只对加载分类归一化，不改写定位值。仍须无可操作控件、无表单/账号入口且整句是加载提示，正文中包含加载词不适用。

账户生成前，若原生关闭遮罩内同时有明确“账号凭证/账户凭证/登录凭证”标题与可操作“保存凭证”等保存功能，节点仅记住本轮观察到了凭证界面，不点击保存、不解码或上传凭证。当后续没有新的明确注册入口而结束无入口/循环观察时，返回 AUTO_ACCOUNT_CREDENTIALS（待适配）。这不等于自动注册、用户 ID 或成功账户证据，不增加 N，也不冒充自动身份统计；若后来发现真实注册表单，仍沿用正常注册及结果核验。
