# 1.20 文件资产与停止回收

版本 1.20.0，Agent 0.16.0。用户要求 APK 以文件名选择、复用和随机去重；停止后已证实清理完成的普通测试应结束占用。覆盖旧包名去重、下载前清单读取及普通停止必须人工核验的相关规则。

## 文件资产

新增签名能力 APK_FILE_ASSETS_V1。ApkMetadata.validationPolicy=FILE_NAME 时必须有 fileName，packageName 可省略；历史结构保持有效。下载、补包只保存文件名、日期、字节数及传输摘要，不读取 AndroidManifest、版本、最低系统或 ABI。版本字段为空、ABI 空数组表示未知，不表示兼容。包名不参与新任务资产去重。旧节点不得接收文件模式资产。

文件名只作为数据，不用于拼接 Shell 或客户端指定的磁盘路径。规范化为不含目录、控制字符的有限长度 APK 文件名；浏览器无文件名时按入口生成稳定名称。相同节点/日期的同名不同文件增加稳定短后缀，保留所有文件；相同名称和相同摘要视为同一文件。不同名称即使包名或字节相同也可独立选择。同一设备会话不重复选择同一规范化文件名，下一会话可复用。磁盘仍以受控缓存键存储，数据库保存名称及日期；不能直接用原始文件名写路径。执行缓存通过日期和文件名查找，并核对冻结文件摘要；历史无名称记录通过来源键兼容读取，不改写历史。

历史记录未保存原文件名时，新执行快照使用 history-来源短键.apk 作为稳定文件名称，并允许从原来源缓存取得文件；不声称恢复了原始文件名，不合并相同包名的历史文件。

手动上传通过可选 X-Apk-Filename 请求头传递 encodeURIComponent 文件名；缺省按来源入口生成名称。认证、CSRF、大小上限、传输摘要、主机指纹、发布验签、缓存回执和租约保留。不解析 APK 内容。新文件模式任务在 Android 实际安装后，以系统安装前后第三方包集合的唯一新增项取得控制包名，只用于打开、关闭和卸载；无法唯一取得时失败并清理设备，不能猜测或卸载原有应用。每个 APP 卸载后再安装下一个，因此两个不同文件可先后安装相同包名。自有客户端身份须在安装后验证白名单再发短期凭据。历史表单流程只接受已知包名资产。

正例：1.apk 与 2.apk 包名相同，同设备串行安装/打开/卸载两次；任意非 APK 文件可被接收，安装时失败；清单不可读不影响下载成功。反例：同一会话重复选择同名文件、文件名目录穿越、用摘要去重合并不同文件名、无包名时冒造包名、安装不明却启动或卸载其他应用，均拒绝。

## 停止与回收

STOP 持久关闭任务开关并设置已有未核验批次 stopRequested，包括 NEEDS_REVIEW；不重新启动任何阶段。在线不等于清理完成。普通 APP_OPEN 或 DOWNLOAD 批次已停止、槽位仍属于本批次且无部署占用、当前已认证 boot 的清理回执、其后新的空闲心跳及无 UNKNOWN/未决提交时，自动记录停止核验并释放槽位。保留原 NEEDS_REVIEW 终态及错误，写 reviewResolvedAt/自动回收原因和审计，不补算成功，不回放已开始尝试。任务轮次随后归并为 STOPPED。

迟到 STOP_ACK 仅能为相同 delivery/fence、仍占本节点槽位、来自当前已认证 boot 的已停止批次提供清理证据；需要设备会话全部 CLOSED，不可越过未闭合会话。不得释放其他批次或部署槽。Agent reconcile 的清理回执仍须校验本批次身份；之后新空闲心跳才自动回收。实际失联、脏环境、未闭合会话、未知提交、旧 boot/fence 或历史表单注册仍保留人工核验。停止按钮不执行全量部署/SDK 检查。

异常恢复按是否改变 boot 区分 AGENT_RESTARTED 与 AGENT_EXECUTION_INTERRUPTED；可选 reason=STARTUP|EXECUTION_ERROR|STOP_RECOVERY 仅记录有限枚举。不能把普通异常一律记成重启。页面停止意图优先显示“停止中，等待清理确认”；清理不确定须解释原因，回收后显示已停止/空闲。

旧 boot 的心跳不能替换已认证 boot 或用于自动释放；新启动先走 Agent reconcile 完成身份和本地资源核对。

执行列表和详情的批次视图增加可选 stopConfirmed。已回收的停止批次以“已停止”展示，cleanup 为 CONFIRMED；原始 status/errorCode 仍用于审计，不能继续把已回收批次显示成尚待核验。

正例：APP 测试异常后已完成清理，点击停止，新的空闲心跳自动释放；重复停止和重复回执幂等。反例：仅点击停止就释放、旧回执释放新任务、缺清理回执自动空闲、未知注册提交被停止抹除，均禁止。

## 验证范围

契约正反例、文件接收及同名处理、相同包名不同文件、安装后包名解析、缓存复用、旧节点保护，以及真实 PostgreSQL/SQLite 的停止/迟到回执/新心跳/未知提交/错 fence 边界。只运行相关测试；普通代码增量发布不重装 SDK/镜像，不启动第三方 APP。生产历史阻塞可在满足上述证据后通过正常停止和心跳路径回收，不能直接改隔离标志。
