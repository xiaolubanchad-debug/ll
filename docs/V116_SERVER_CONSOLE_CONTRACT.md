# 1.16 服务器工作台与当前流程契约

版本 1.16.0。当前业务为下载 APK、安装、打开、处理启动遮挡、前台停留 10 秒、卸载及清理。每台 EC2 同时一台模拟器，设备内随机选择不重复的多个 APP；账户回传是自有测试客户端的独立统计。此契约覆盖旧界面把注册设置放在日常入口的做法，不改写历史配置、结果或节点协议。

## 日常入口

登录后默认进入服务器页。列表每行显示名称、SSH 地址、部署状态、执行状态、任务配置与操作：部署、开始、停止、检查、日志、配置和连接资料。型号、代理和 APP 数量在任务配置中设置；同页填写、保存，保存本身不启动任务。

任务下拉框只选择该服务器已有且未归档的任务。活动任务优先显示并锁定选择；切换空闲任务只是本页选择，开始后中台持久执行状态为准。没有任务时直接在该服务器新建配置，也可明确导入已有配置；不得把另一服务器任务的 nodeId 静默改写。原任务中心继续提供详细历史及版本维护。

开始、停止复用现有 task-plans/control 接口，保持数据库锁、If-Match、幂等键和节点清理回执。停止始终针对服务器上的实际活动任务，即使选择已改变也不能停错对象。旧独立批次占用服务器时可停止实际批次；部署占用时停止部署，不能伪装成业务停止。已请求停止显示“等待清理”，不可立即显示空闲。

完成目标或耗尽上限后的再次开始必须明确确认“新增一轮”，使用 NEW_ROUND；不得把普通 START 的无新增行为表现为已执行，也不得自动重复未知提交。历史 REGISTRATION 任务不能在服务器快捷入口直接启动，须显式编辑并另存为 APP_OPEN，旧记录保留。

部署按钮在同页展开固定发布选择和 SDK 许可，仍需已核验主机指纹。检查保留 SSH 与环境真实核验，隔离解除不自动执行。删除服务器沿用安全归档条件；在线、忙碌或隔离节点不提供强制删除。凭据不回显。

CPU 使用率目前没有节点实时采样，显示“未采集”，不能根据在线状态伪造百分比；内存仅显示现有心跳报告的总量，离线或无值显示未知。该版本不为界面改动重装 EC2 的安卓环境。

NodeView 新增可选 activeRunId、activeOperationId（UUID 或 null），直接来自 NodeSlot；activeStopRequested 为该占用对象的真实停止意图。字段供快捷停止和日志定位，不返回连接秘密。执行中的实际占用优先于本页下拉选择，操作前重新读取节点和任务版本；状态变化由服务端锁与状态校验最终裁决，不能只凭浏览器旧快照执行。

## 当前流程与历史

配置编辑器默认 APP_OPEN / DOWNLOAD_ONLY，不提供注册入口识别、用户名密码表单或注册成功标识设置。旧配置载入必须先提示且显式转换草稿，保存为新版本才生效，不能自动修改数据库。高级 JSON 仍经运行时校验，禁止从当前编辑器重新保存注册模式。

主导航提供服务器、任务配置、执行历史、APK 资源、代理、测试数据及工作台；旧注册记录移至历史兼容区并标为历史。历史内容、未知结果人工核验及账户审计查看继续可用。工作台优先展示 APP 打开完成、失败、尝试和自有上报数，打开完成不代表注册成功。

GET /console/overview 增加可选 appOpens 对象，字段 completed、failed、attempts、pending、stopped、needsReview、testReports 均为非负整数，拒绝额外字段。前六项限定 executionPlan.openPolicy 存在的 REGISTER 批次、cacheDay 对应北京时间业务日、已进入尝试的任务；completed 还要求 SUCCEEDED + APP_OPEN。testReports 只计该范围的真实 TestRecord。nodeId 筛选一致应用。旧 registrations 字段保留原语义，不混入 APP_OPEN。

## 正反例与验收

正例：服务器选择配置 A，开始后显示准备/下载/运行；点击停止后显示等待清理，收到回执才空闲；已完成时确认新增一轮后才再执行。反例：选择 B 后把 A 的停止按钮停到 B、离线显示运行中、缺失采样显示 CPU 0%、把打开次数显示为注册成功、保存配置就自动开始、默默转换旧注册配置，均不允许。

验证覆盖服务器快捷操作请求归属、幂等和等待清理状态；配置保存及历史转换；离线/忙碌/隔离禁用；分页后任务不丢失；主导航和移动端布局；工作台 PostgreSQL 真实聚合与节点筛选；既有完整回归、契约、lint、typecheck、build。真实部署与线上只读 UI 验证分开记录，不额外启动第三方 APP，不修改正在进行的三日验收配置。
