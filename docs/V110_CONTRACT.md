# 1.10 默认内容隔离与真实功能测试

2026-10-29，Agent 0.8.0。HTTP 契约为 1.10.0，节点与配置协议仍为 1.0。中台先升级，再部署签名 Agent；本契约覆盖旧截图上传和展示规则。

## 默认与范围

内容隔离为强制默认行为。execution.contentIsolation 可省略或为 true；false、其他模式及未知字段均拒绝。已有不可变配置不改写，省略字段同样启用。中台显示隔离状态，不提供关闭开关。

真实安装、启动、代理连接、控件定位、输入、唯一提交和 APP 结果验证保留。自动导航仍仅操作已经识别的注册、登录、账号和必要关闭/同意入口；无法确认的页面停止等待适配。隔离不提供任意浏览内容或修改第三方 APK 的入口，不把遮挡等同于目标合法或获得授权。

隔离保证的是测试系统不保存、上传或展示新产生的原始业务画面、原始界面树、OCR 正文。必要的页面读取、像素稳定性检查和本地 OCR 只在执行节点内存中进行，不向外部识别服务发送原图。APP 自身仍可能加载、渲染或在模拟器内缓存内容；独立模拟器结束后清理其工作目录。要从源头阻止媒体加载，需要 APP 测试版本配合。本次不增加网络拦截、解密 HTTPS 或防火墙规则。

## 功能证据

新增 FunctionalEvidence 运行时 Schema。证据是受限 JSON，不是截图：schemaVersion=1.0、kind=FUNCTIONAL_EVIDENCE、stage=RESULT/DISCOVERY、outcome=SUCCEEDED/FAILED/UNVERIFIED、verification=AUTO_EXPLICIT_UI/CONFIGURED_LOCATOR/NO_SUBMISSION、sourceDigest 和最多 64 个功能控件角色及矩形。角色仅允许 USERNAME、PASSWORD、PASSWORD_CONFIRM、REGISTER、LOGIN、ACCOUNT、CONSENT、RESULT；不包含原文、资源 ID、XPath、图片、URL、账户值或原始 UID。结果证据必须为已验证结果；发现阶段只能为 UNVERIFIED/NO_SUBMISSION。

线上的 ArtifactInput 只接收 kind=functional-evidence、redaction=CONTENT_ISOLATED，正文仍以 dataBase64 传递，解码后上限 64 KiB。节点入库、上传、中台接收及读取均重新执行 Schema 与规范 JSON 校验，拒绝原始 PNG、HTML、重复键、额外字段和将内容藏入未知属性的情况。磁盘扩展名为 .json。幂等、所属任务、fence、摘要、上传数量与迟到证据规则不变。

APP_UI 继续表示 Agent 在真实 APP 中验证结果，不表示示意图证明成功。成功/明确拒绝必须有持久提交意图和相同 outcome 的 RESULT 功能证据；DISCOVERY 证据不能让任务成功。读取失败、证据验证失败或提交后无法确认仍为 UNKNOWN，不自动重发。中台结构示意必须明确标注“非原始 APP 画面”，只显示固定角色名称和结构化状态。

正例：注册后观察到明确成功标识，保存其稳定界面摘要及功能控件结构，计入一次成功。反例：仅进入首页；只生成示意图；使用发现阶段记录或其他任务的证据判定注册成功；正文夹带图片、账号或任意 UI 文本。

## 升级与历史

签名发布新增 CONTENT_ISOLATION_V1 能力。完整/注册任务在创建、领取、接收及读取执行配置时要求此能力与 Agent 0.8.0，旧节点提示升级；下载与代理检查继续兼容。每日计划和任务中心同样展示升级原因。升级前必须等待正在执行的任务停止并收到清理回执，不在旧节点注册中途切换中台。

历史截图元数据、账户、提交和审计记录保留；截图列表不返回历史图片，原始图片内容接口统一返回 CONTENT_ISOLATION_REQUIRED，不读取或返回原图。旧版未上传图片不得在升级后补传，旧证据不能伪装成新功能证据。已有历史文件和备份的保留/清理是单独的数据留存事项，本次不静默删除历史，也不声称它们已被物理清除。

## 验证

正反例检查包括默认开启、拒绝关闭、受限证据结构、原始图片/文本注入、重复键、证据结果不一致、旧节点拒绝、旧截图不可访问、节点持久化拒绝原图及重启补传。真实 PostgreSQL/SQLite、浏览器和 Appium 边界验证单次提交与未知结果不重发；自有 Android APK 验证真实注册、自动身份独立观察和导航壳跳过。实际产品与住宅代理另行验收，不复用已弃用配置。

已在 Ubuntu 26.04 / KVM EC2 使用带自有背景图片的三个 APK 完成真实安装启动：用户名密码注册仅提交一次并取得明确成功界面；游客身份单独观察且零提交；导航壳明确跳过且零提交。证据及节点 SQLite 仅保存通过校验的功能 JSON，执行证明目录没有原始 PNG、UI XML 或 OCR 正文文件，三个模拟器均确认清理完成。真实产品尚未联测。
