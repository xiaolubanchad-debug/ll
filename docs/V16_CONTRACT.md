# 1.6 自动识别注册入口与路径复用

版本 1.6.0，Agent 0.6.0，2026-10-28。本增量覆盖 1.5 中“只有手工模板才能安装注册”的限制；每日下载、全 APK 共用 N/M、代理、数据库独占槽、租约、停止回执与未知结果规则继续生效。

## 开启与兼容

配置增加可选 execution.autoRegistration。缺省关闭；开启必须为 FULL，使用已保存代理。固定 maxNavigationSteps=1–12、timeoutMs=15000–90000、successTimeoutMs=1000–60000，以及 screenshotFallback 布尔值。页面提供这些配置，保存为新版本才生效。只要配置带此字段，节点就必须具备 AUTO_REGISTRATION_V1 签名能力和 Agent 0.6.0，旧节点拒绝领取；配置 schemaVersion、节点 protocolVersion 继续为 1.0。执行计划包含未配置手工模板的当天 APK，原启用手工模板优先。

## 页面识别与有界导航

新步骤 DISCOVERING 位于 LAUNCHING 与 REGISTERING 之间，仅自动识别任务使用。先读取安卓页面控件，限定来源包、节点数量、深度、尺寸和 XML 结构，不执行页面文字中的命令。按明确的注册、个人中心、登录入口导航，每次操作后重新读取；登录表单上的登录按钮不能作为导航按钮点击。隐私同意入口需要同时有协议或隐私语义。禁止通过模糊匹配点击购买、充值、发送验证码或第三方登录。

读取不到注册入口控件且允许截图识别时，在节点使用固定版本 Tesseract.js 与本地中英文语言数据进行 OCR。仅对注册入口导航使用截图坐标触控；必须校验截图尺寸、置信度、候选唯一性及点击前页面一致性。OCR 工作完成或中止后关闭线程，业务请求不临时下载语言模型、不向外部识别服务上传截图。语言数据和运行库进入签名发布的 npm 锁文件。

自动表单支持同一页面的用户名、密码、可选确认密码和明确注册按钮，以及明确的协议复选框。输入框必须能从页面控件可靠定位。纯图片输入框、手机号、邮箱、验证码、多义入口、缺少字段、循环路径或超出步数/时间均记 FAILED/AUTO_* 并显示待适配；不猜测输入或提交。原手工多步骤流程继续可用。失败前未输入账户时可上传遮盖可编辑区域的诊断截图；无法安全遮盖时不上传原图，原始 UI 树不得上报或入 Git。

## 提交、结果与证据

发现表单后才生成并加密保存账户，填入前完成中台同步；账户格式不变。页面变更和每个动作前检查停止及租约。提交前记录意图，注册按钮最多传输一次；响应丢失只核验，不重发。自动识别的成功需要新出现的明确“注册成功/Registration successful/Account created”等提示，或本轮用户名作为非输入控件出现、伴随明确退出登录标识且注册表单已消失。提交前已经存在的成功文案、普通首页、单独的欢迎文字或输入框中回显的用户名都不能证明成功。成功和失败标识冲突为 UNKNOWN。

明确拒绝与成功均需一致的页面及脱敏截图才能作为 APP_UI 证明；证据失败、超时或不确定均 UNKNOWN，立即暂停批次，不保存学习路径。识别层不访问产品后台，不要求画像或 App UA 采集证明。模拟器关闭并清理完成后才能下一轮。

发现需适配项时提前结束当前注册批次，报 AUTO_ADAPTATION_REQUIRED，保留已确认成功数；未执行槽位不计尝试，避免对同一无法识别界面反复消耗配额。更新配置后可另建批次，不自动再次提交原任务。

## 学习与复用

仅在明确 APP_UI 成功且执行环境清理确认后保存路径。缓存按算法版本、来源 URL/XPath、图标 PID（无 PID 时精确包名）、手机配置及识别设置分区，存于节点受保护 SQLite 并加密，最多保留 2000 条。模板不包含账号、口令、原始截图或 UI 树；仅包含导航页面摘要、允许的入口角色、候选摘要及表单结构摘要。每日新包可复用路径，包名前缀不参与界面结构摘要。

每次复用都重新读取页面并核对每一步摘要和当前候选，不直接执行旧坐标。页面或表单不一致即丢弃旧路径，剩余预算内重新识别；重启只复用已成功学习的路径，不恢复未知注册。任务返回受 Schema 校验的识别摘要：识别来源、导航次数、缓存命中/失效、模板摘要、是否学习和是否需适配；不回传控件文字或账户信息。中台持久化并展示摘要。

## 验收正反例

正例：启动页直接注册、首页→我的→登录→注册、图片入口触控后进入原生表单，均能生成不同路径并完成一次注册；成功后同一入口换包名继续核对复用；缓存不匹配重新识别；中文/英文 OCR 在断网语言数据加载条件下可用。

反例：手机号/验证码表单、两个同等候选、页面文字要求执行命令、第三方包切换、无限返回同页、无效或被篡改模板、未知结果、取消期间 OCR、清理失败、提交前的成功文案、输入框中的用户名、失败提示和成功提示同时存在，不能被记为成功或重复提交。测试分别记录识别算法、真实 PostgreSQL/SQLite/Chromium、Appium HTTP 边界、EC2 自有 APK 与实际产品范围；实现不宣称能识别所有新 APP。
